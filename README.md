## 汉化范围

整合包里有 **233 个模组自带官方中文**，本包不做重复翻译，只补齐了覆盖不到、或做错的地方：

| 范围 | 规模 |
|---|---|
| 模组界面 / 物品 / 实体（语言文件层）| **18.4 万余条**。其中 **409 个模组游戏内的中文完全依赖本包**（官方 jar 不带中文），另有 **142 个模组**在官方基础上补齐了缺翻的键 |
| 字节码硬编码文本（语言文件够不着的界面字）| 151 个模块，**1,452 条**（RFTools 系为主）|
| RFTools 全系图形界面 | **24 个** `.gui` 文件 |
| 资源蜜蜂（蜂名 / 基因 / 蜂笼 / 服务器数据迁移）| **467 种蜂** |
| 结构罗盘 / 自然罗盘的结构名 | **799 条** |
| 任务书（FTB Quests）| 官方中文 + 本包补丁 **388 条**（补章节缺口 / 标题副标题；术语·品牌·维度名以模组自译名 / 物品名 / 社区标准为单一真源统一，如 Allthemodium→ATM、Just Dire Things→可怖之物、挖矿维度、彼岸；修 3 处 `&`+中文 非法颜色码崩溃）|
| **主菜单首页**（本版新增）| 重绘 **14 张**按钮图为中文：单人游戏 / 多人游戏 / 选项 / 退出 / 模组 / 语言 / 租用服务器 |
| 机制层修复 | 传送石碑维度名、神秘农业作物名、闪光生物名等 |

**本包还替上游修了一批 bug**：不少模组自带的官方中文本身是错的——例如死亡提示的占位符写错会导致该提示格式化失败、译文张冠李戴（把「步行辅助」写成「夜视」之类）。这些本包都已修正。

## 客户端安装

1. 从 [Releases](../../releases) 下载 `…-客户端-vX.zip` 并解压。
2. 把解压出的**整个文件夹**放进 ATM10 实例根目录——就是含 `mods/`、`options.txt` 的那一层
   （HMCL / CurseForge / Prism 里右键实例 → 打开实例文件夹）。放错也没关系，安装器会让你手动输入路径。
3. 运行安装器：
   - **Windows**：双击 `双击安装-Windows.bat`
   - **macOS / Linux**：终端运行 `bash install.sh`
4. 选 **[1] 应用汉化**。安装器会自动备份将被覆盖的文件、在 `options.txt` 里启用汉化资源包，
   并询问是否安装可选的 **JEI 拼音搜索**（用拼音搜物品）。

**确认成功**：进游戏 → 选项 → 资源包，「ATM10汉化包-7.2」应在「已启用」一侧；回到主菜单，按钮应是中文。

**卸载 / 回退**：再次运行安装器选 **[3] 恢复备份**，一键回到安装前状态。

## 服务端安装

蜂笼蜂名、建造机聊天反馈等文本由**服务端**生成，只装客户端救不了。
下载 `…-服务端-vX.zip`，按包内 `README-服务端.md` 覆盖到服务器并重启。

⚠️ 不要把**客户端包**覆盖到服务器——其中的作物名配置是纯客户端的，上了服务器会让所有玩家进服刷错误。

## 常见问题

- **装完还是英文？** 进游戏检查 选项 → 资源包，「ATM10汉化包-7.2」必须启用（安装器一般已自动处理）。
- **改动不生效？** 资源包类改动 **F3+T** 重载即可；VaultPatcher 硬编码文本、主菜单按钮图需**完整重启游戏**；任务书需**重进世界 / 重连服务器**。
- **蜂笼上的蜂名是英文？** 老蜂笼里的名字是抓蜂时烙进去的。装了服务端包后，把蜂笼放进背包待几秒会自动转正；**你用命名牌起的名字永远不会被改**。
- **JEI 里有一行灰色的 `productivebees:xxx`？** 那是模组给所有语言玩家显示的 ID 行，不是漏翻。

## 已知限制（诚实说明）

- **Sodium「粒子效果」设置里的原版粒子名无法汉化**（Cloud / Ash / Crit…）。这是 sodium-extra 0.9.3 自身的问题——它连**自己内置的**原版粒子中文都渲染不出来（选项注册时机导致翻译键解析失败），资源包无法干预。模组自定义粒子不受影响。
- 极少数模组把英文**画进了贴图**（技术边界，语言文件无能为力）。
- 各模组自带的官方中文若有错漏，本包尽力修正但不保证穷尽。发现漏翻 / 错译请
  [提 Issue](../../issues)，附截图与位置。
