# All the Mods 10 · 7.2 汉化补丁 —— 绿油油版

适用于整合包 **All the Mods 10 v7.2** 的完整汉化。整理／补译：**星野夢華 (Hoshino Yumeka)**，
基于 BBSMC 汉化二次修改（改动幅度较大，故独立命名）。

## 汉化了什么

一句话：**你在游戏里能看到的字，基本都是中文。**

| 范围 | 规模 |
|---|---|
| 模组界面 / 物品 / 实体（语言文件层） | **603 个模组，189,000+ 条文本** |
| 任务书（FTB Quests 官方中文 + 本包补丁 190 条） | 32 个章节零缺口 |
| 字节码硬编码文本（语言文件够不着的界面字） | 151 个模块，1,452 条 |
| RFTools 全系图形界面文件 | 24 个 `.gui` 全翻 |
| 资源蜜蜂（蜂名 / 基因 / 蜂笼 / 服务器数据迁移） | 463 种蜂全覆盖 |
| 结构罗盘 / 自然罗盘的结构名 | 补 114 个 |
| Sodium 视频设置的模组粒子选项 | 补 431 个 |
| 传送石碑维度名、神秘农业作物名、闪光生物名等机制层修复 | 若干 |

覆盖不到的地方（如个别模组把英文画进贴图）属于技术边界；发现漏翻请
[提 Issue](../../issues)，附截图与位置，通常当天修。

## 客户端安装（每个玩家）

1. 从 [Releases](../../releases) 下载 `…-客户端-vX.zip` 并解压；
2. 把解压出的**整个文件夹**放进 ATM10 实例根目录
   （含 `mods/`、`options.txt` 的那一层，通常是 `.minecraft/versions/All the Mods 10/`；
   放错位置也没关系，安装器会让你手动输入路径）；
3. 运行安装器：
   - **Windows**：双击 `双击安装-Windows.bat`
   - **macOS / Linux**：终端运行 `bash install.sh`
4. 选 **[1] 应用汉化**。安装器会自动备份将被覆盖的文件、在 `options.txt`
   里启用汉化资源包，并询问是否安装可选的 **JEI 拼音搜索**（用拼音搜物品）。

后悔药：菜单选 **[3] 恢复备份**，一键回到安装前状态。

## 服务端安装（开服的人）

蜂笼蜂名、建造机聊天反馈等文本由服务端生成，只装客户端救不了。
下载 `…-服务端-vX.zip`，按包内 `README-服务端.md` 覆盖到服务器并重启。

⚠️ 不要把**客户端包**覆盖到服务器——其中的作物名配置是纯客户端的，
上了服务器会让所有玩家进服刷错误。

## 常见问题

- **装完还是英文？** 进游戏检查 选项 → 资源包，「ATM10汉化包-7.2」必须启用
  （安装器一般已自动处理）。
- **蜂笼上的蜂名是英文？** 老蜂笼里的名字是抓蜂时烙进去的。装了服务端包后，
  把蜂笼放进背包待几秒会自动转正；**你用命名牌起的名字永远不会被改**。
- **JEI 里有一行灰色的 `productivebees:xxx`？** 那是模组给所有语言玩家显示的
  ID 行，不是漏翻。
