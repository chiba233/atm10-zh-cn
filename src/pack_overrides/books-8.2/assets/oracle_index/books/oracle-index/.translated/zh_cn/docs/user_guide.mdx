---
title: 用户指南
---

Oracle Index是一款游戏内客户端文档模组，旨在提供[moddedmc.wiki](https://moddedmc.wiki/)内容的游戏内浏览视图。

模组开发者可选择将wiki纳入其模组，并借助Oracle索引模组在游戏中显示。按下wiki快捷键（默认为[H]）即可打开Oracle索引界面。
你无需特殊书籍物品等。退出界面时，系统将记住你上次离开的位置。

仅当某模组已安装，且该模组开发者选择将来自moddedmc.wiki的文档一并作为Oracle索引wiki纳入时，你才可查看该模组的文档。

## 模组换位
屏幕左侧将显示当前所选模组的导航栏。若要切换至其他模组，只需点击导航栏上方的模组标题栏。
此时将弹出下拉菜单，供你选择要浏览的模组。

## 物品链接
模组开发者可在游戏内物品上添加wiki链接。若某物品存在wiki页面，你将在其物品提示中看到一个小图标。
当查看物品提示时，按住[ALT]键即可打开对应的wiki条目。

## 语言
若Wiki提供与你的Minecraft语言完全对应的译文，Oracle索引会自动使用。页面内容、导航元数据、页面标题、内置控件、标注框和状态消息都可以翻译。

在结构版本1的Wiki中，翻译后的页面应按原页面路径放在`translated/<locale>/`下；旧格式Wiki则放在`.translated/<locale>/`下。若翻译页面或元数据文件缺失，Oracle索引会回退到基础语言资源。

搜索功能目前只索引基础语言的页面文本。若对应译文存在，搜索结果仍会打开翻译后的页面，显示的页面标题也会使用当前语言。
