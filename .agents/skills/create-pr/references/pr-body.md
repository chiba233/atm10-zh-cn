# PR 正文模板

「改了什么」与「怎么验证的」两节必写。其余各节只在对审阅有用时加。小 PR 保持小，不为了填模板加节。

标题与提交标题用同一格式：`<类型>: <动作 + 对象> (#N)`。

## 改了什么

先写问题或新功能，再写结果。一到三句。

## 依据

改译名时用真源表：

| 来源 | 译名 |
|---|---|
| MC百科条目页 [/item/<id>.html](https://www.mcmod.cn/item/<id>.html)（注册名 `<命名空间>:<id>`） | … |
| CFPA `projects/assets/<项目>/<版本>/` | … |
| 模组 jar（<版本>） | … |

其他类型写对应的证据：增量口径与键数、jar 的 fileID 与 sha256、反例测试名。

## 影响范围

写这次改动影响到的表面，以及查过但没有引用的地方。改动只影响一处时，写一句即可。

## 怎么验证的

- CI：通过的检查名
- 未验证：没有验证的条件，例如「未在游戏内验证」
